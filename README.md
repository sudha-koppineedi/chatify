# Chatify 💬

Chatify is a simple MERN-based chat application that allows users to create, view, edit, and delete chat messages.  
This project was built to practice backend development using Node.js, Express, MongoDB, and Mongoose.

---

## 🚀 Features

- Create new chat messages
- View all chats
- Edit existing messages
- Delete chats
- Server-side rendering using EJS
- RESTful routing with method-override

---

## 🛠 Tech Stack

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

**Templating**
- EJS

**Other Tools**
- Method Override
- CSS (basic styling)
